# registry/ — copyable behaviors

The shadcn model: nothing in here is published. A registry entry is
vendorable source that travels with three things it is never separated
from — its **tuned constants**, its **perceptual-floor tests** (budgets
pinned to real hand speeds, the named peers of the theorems), and its
**archive citations** (`archive#N` = three-ui@362c5a1 decisions.md
entry N).

**glass/** (archive#38–#43) is the first shipped pack: the SDF
compositor as vendorable source, byte-welded to the preserved Lab 012,
with the capillary law's TS twin and the view-space-z ordering
regression (`tests/registry/glassPack.test.ts`).

**flight-card/** (archive#58–#62) is a charter, deliberately: the laws
are kernel contracts, the scene machinery is one organism inside the
preserved Lab 014, and extraction waits for a second consumer
(decisions.md #10). Its README is the inventory; the pack test welds
the charter's claims to the kernel and the reference scene.

Still planned: control kit (archive#2/#4/#7) — `Dial` already ships
from the binding; Toggle/Slider wait for a consuming lab.

The **focus / spatial-nav pack** (archive#13–#15) resolved into the
binding instead of this directory (decisions.md #9): Phase 3 shipped
the mechanism as exported API (`FocusScene`, `FocusOrbitRig`, the lib
beside them), so the pack's payload — the six fidelity suites,
including the 33 browser-captured field rects — crossed as in-package
tests at `packages/react/src/lib/*.test.ts`, and `docs/focus.md` is
the behavior's contract doc. Import-code, not copy-code.

Registry code imports the library only through the `anamorph` barrel —
if a behavior can't be built without patching the kernel, that is a
kernel bug, not a registry workaround.
