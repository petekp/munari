# registry/ — copyable behaviors

The shadcn model: nothing in here is published. A registry entry is
vendorable source that travels with three things it is never separated
from — its **tuned constants**, its **perceptual-floor tests** (budgets
pinned to real hand speeds, the named peers of the theorems), and its
**archive citations** (`archive#N` = three-ui@362c5a1 decisions.md
entry N).

Planned packs, per the seed manifest: flight-card / drag
(archive#58–#61), glass (archive#38–#43), focus / spatial-nav
(archive#13–#15), control kit (archive#2/#4/#7).

Registry code imports the library only through the `anamorph` barrel —
if a behavior can't be built without patching the kernel, that is a
kernel bug, not a registry workaround.
