# Bounce paintings

Each image is a faithful photographic reproduction of a public-domain painting,
downloaded from Wikimedia Commons on 2026-11-22. Each was resized to 720 px tall
and encoded as WebP. The light bounce viewer displays them at 360 CSS px tall.
